# converter_svg_to_pdf
https://converter-svg-to-pdf-1.onrender.com

Минимальный web интерфейс с полем для загрузки SVG файла. После загрузки предоставляет возможность скачать готовый PDF файл.
API endpoint для генерации PDF документа из SVG файла отдаёт ссылку на файл.
В PDF документ добавляются поля для обрезки (рамка вокруг контента, 1 см до контента и 1 см после) и Watermark с именем.

* Реализованный функционал покрыт тестами RSpec.
* Соблюдается REST.
* Используются функции REST API, Service Object, ActiveStorage
* Файлы хранятся в YandexStorage.

Дополнительно плинаруется
* Интеграция AI для работы с SVG. Здесь можете сделать все что угодно: от автоматической оптимизации кода SVG (удаление лишних атрибутов, объединение путей) до изменения дизайна исходного документа.
* Swagger документация
* сериализация (ответ контроллера должен формироваться через сериализатор с использованием одного из распространённых инструментов. Например, Blueprinter или JSONAPI::Serializer. Возвращать «сырые» объекты или использовать to_json недопустимо)
